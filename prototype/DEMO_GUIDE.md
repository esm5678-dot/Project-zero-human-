# ZERO OPS three-minute guided demo

Open `demo.html` locally. It is a static offline presentation using a fictional delivery inquiry. No server, API, customer data, login, or payment is required.

Flow: 1) classify a fictional inquiry; 2) reveal a rule-based reply draft; 3) change its status to completed. Reset restarts the demo.

This guided demo is separate from `index.html`, the existing offline MVP. It is not a deployed service or a production customer-support tool. No customer outreach or public deployment is authorized by adding this file.

Acceptance checks to perform in a browser: controls start disabled where appropriate; progress increments 0→1→2→3; selecting completed shows confirmation; reset clears state; no network requests; mobile viewport and keyboard accessibility.
